name: Study personality survey intent
description: Intended framing, privacy, scoring, and history behavior for the study-personality survey.
---

The study-personality quiz is a self-reflection tool, not a scientific test. No answer is right or wrong, and no profile is better than another. Selected answers contribute equally to profile patterns, but must not be presented as a grade or correctness score. Reflection prompts are for private thought or discussion and must not be collected. Preserve each attempt so students can see how their profile changes over time.

**Why:** the user supplied these requirements with the quiz content and emphasized that results are reflective, private, and useful for comparing retakes.

**How to apply:** use neutral language, show profile distributions and blends/ties, do not reveal a correct choice, and retain the result history for the account.
