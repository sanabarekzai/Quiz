Treat Study Blocker Check-In as an ungraded self-reflection tool, not a diagnosis or a measure of discipline. Use supportive, nonjudgmental language. The user chose an under-35% threshold for the Steady Builder outcome because the supplied under-25% rule could not occur when 12 answers each award exactly one point.

**Why:** the result profiles are intended to give practical study tips, and the user explicitly selected the adjusted threshold after reviewing the scoring conflict.

**How to apply:** preserve the under-35% rule unless the user changes it; keep it separate from right/wrong quizzes and do not collect the reflection prompts.
